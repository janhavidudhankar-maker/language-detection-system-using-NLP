# Language Detection System Using NLP

## Introduction
Language Detection System is an NLP-based project that identifies
the language of a given text.

## Objective
To develop a system that automatically detects the language of
user-provided text using Natural Language Processing and Machine Learning.

## Technologies Used
- Python
- NLP
- Machine Learning
- Scikit-learn
- Pandas
- NumPy

## Features
- Detects the language of input text
- Simple and user-friendly
- Supports multiple languages

## Project Workflow
1. Collect the dataset
2. Preprocess the text
3. Extract features
4. Train the machine learning model
5. Predict the language
6. Display the result

## How to Run
Install the required libraries:
pip install -r requirements.txt
Then run:
python app.py

## Conclusion
The Language Detection System demonstrates how NLP and Machine Learning
can be used to automatically identify the language of text.
